Endpoint S3 SCM Plugin

The Endpoint S3 SCM plugin allows Jenkins to download a ZIP archive from S3-compatible storage and safely extract it into the job workspace. It is designed for “checkout-only” scenarios where pipeline sources, shared libraries, or configuration files are stored as ZIP archives in S3-like object storage.

Plugin version:1.0
Requires Jenkins:2.361.4+

How it works

  • Connects to a configured S3-compatible endpoint using username/password credentials (access key / secret key).
  • Performs a HEAD request to check object size before download.
  • Rejects objects larger than the built-in limit to avoid downloading huge archives.
  • Downloads the ZIP file to a temporary location with retry logic.
  • Validates the downloaded file as a ZIP archive.
  • Safely extracts the ZIP into the workspace with Zip Slip protection.
  • Optionally strips a common top-level directory from the archive.
  • Removes the source ZIP from the workspace after extraction.
  • Does not support polling or changelog; this SCM is strictly “checkout-only”.

Pipeline usage

MinIO example

checkout([$class: 'EndpointS3SCM', endpoint: 'http://minio.internal:9000', bucket: 'jenkins-pipelines', key: 'myapp/pipeline.zip', credentialsId: 'minio-access', region: 'us-east-1', stripTopLevelDir: true ])

AWS S3 example

checkout([$class: 'EndpointS3SCM', endpoint: 'https://s3.eu-west-1.amazonaws.com', bucket: 'company-pipelines', key: 'prod/deploy.zip', credentialsId: 'aws-jenkins', region: 'eu-west-1', stripTopLevelDir: true ])

Custom retry settings

checkout([$class: 'EndpointS3SCM', endpoint: 'https://storage.example.com', bucket: 'pipelines', key: 'v1.2.3/build.zip', credentialsId: 's3-access', region: 'us-east-1', stripTopLevelDir: true, maxRetries: 5, retryDelayMs: 2000 ])

Important notes

Endpoint is always required.
The plugin does not assume AWS defaults; you must specify the full endpoint URL, even for AWS S3.
Jenkinsfile must be reachable after extraction.
For Pipeline script from SCM, ensure that after extraction (and optional stripping) the Jenkinsfile is located at the path configured in the job’s Script Path (by default simply Jenkinsfile in the workspace root).
Source ZIP is removed from the workspace.
After successful extraction, the downloaded ZIP file (and self-contained ZIP copies inside the archive matching the same key) are removed from the workspace to keep it clean.

Troubleshooting

Error Cause Solution
Jenkinsfile not found Jenkinsfile is not in the expected location after extraction. Check the archive structure.
Enable stripTopLevelDir if you have a wrapper folder (e.g. myapp/Jenkinsfile), or update the job’s Script Path.
Archive is too large Object size exceeds the plugin’s maximum allowed size. Reduce the archive size or adjust the limit in plugin configuration.
Connection refused / Host unreachable Endpoint URL or network configuration is incorrect. Verify endpoint, port, DNS and firewall settings.
AccessDenied / HTTP 403 Provided credentials do not have permission to read the object. Check bucket policy and credentials permissions.
NoSuchKey / HTTP 404 Bucket or key is wrong. Double-check bucket name and object key.
Workspace is empty in pipeline stages Only the internal @script workspace was populated. For Pipeline script from SCM, add an explicit checkout scm or checkout([$class: 'EndpointS3SCM', ...]) inside a stage to populate the main workspace.
