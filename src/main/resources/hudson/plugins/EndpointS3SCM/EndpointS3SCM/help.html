Endpoint S3 SCM Plugin

The Endpoint S3 SCM plugin allows Jenkins to find the latest ZIP archive in an S3-compatible storage prefix, download it, and safely extract it into the job workspace. It is designed for checkout-only scenarios where pipeline sources, shared libraries, or configuration files are published as ZIP archives in S3-like object storage.

Plugin version: 1.0
Requires Jenkins: 2.361.4+

How it works

  • Uses one or more configured S3 locations.
  • Tries locations by priority: lower priority value is tried first.
  • Searches the configured prefix for non-empty .zip files.
  • Selects the latest ZIP archive by S3 lastModified timestamp.
  • Rejects archives larger than the built-in limit.
  • Downloads the selected ZIP file to a temporary location with retry logic.
  • Validates the downloaded file as a ZIP archive.
  • Safely extracts the ZIP into the workspace with Zip Slip protection.
  • Optionally strips a common top-level directory from the archive.
  • Does not support polling or changelog; this SCM is strictly checkout-only.

Pipeline usage

Single MinIO location

checkout([$class: 'EndpointS3SCM', prefix: 'myapp/releases/', locations: [[ name: 'primary', endpoint: 'http://minio.internal:9000', bucket: 'jenkins-pipelines', credentialsId: 'minio-access', region: 'us-east-1', priority: 10 ]], stripTopLevelDir: true ])

Two locations with failover

checkout([$class: 'EndpointS3SCM', prefix: 'prod/deploy/', locations: [ [ name: 'primary', endpoint: 'https://s3-primary.example.com', bucket: 'company-pipelines-primary', credentialsId: 's3-primary-access', region: 'us-east-1', priority: 10 ], [ name: 'secondary', endpoint: 'https://s3-secondary.example.com', bucket: 'company-pipelines-secondary', credentialsId: 's3-secondary-access', region: 'us-east-1', priority: 20 ] ], stripTopLevelDir: true, maxRetries: 5, retryDelayMs: 2000 ])

AWS S3 example

checkout([$class: 'EndpointS3SCM', prefix: 'releases/app/', locations: [[ name: 'aws-eu', endpoint: 'https://s3.eu-west-1.amazonaws.com', bucket: 'company-pipelines', credentialsId: 'aws-jenkins', region: 'eu-west-1', priority: 10 ]], stripTopLevelDir: true ])

Provider Endpoint example Notes

Ceph RADOS Gateway http://ceph-gateway:8080 Use the S3 gateway URL.
LocalStack http://localhost:4566 Local AWS S3 emulator for testing.

Important notes

The plugin downloads the latest ZIP by lastModified timestamp.
Make sure only valid release ZIP archives are placed in the configured prefix. Non-ZIP files are ignored.
All configured buckets should be consistent.
When multiple locations are configured, they should contain equivalent release archives under the same prefix. During failover the plugin searches the selected source independently.
Jenkinsfile must be reachable after extraction.
For Pipeline script from SCM, ensure that after extraction and optional stripping the Jenkinsfile is located at the path configured in the job’s Script Path.

Troubleshooting

Error Cause Solution
No ZIP files found in prefix No non-empty .zip objects were found in the configured prefix. Check the prefix and verify that release archives are uploaded there.
All S3 sources failed Every configured location failed during object search or download. Check endpoints, buckets, credentials, network access and source priorities.
Jenkinsfile not found Jenkinsfile is not in the expected location after extraction. Check the archive structure, stripTopLevelDir, and job Script Path.
Archive too large Object size exceeds the plugin’s maximum allowed size. Reduce the archive size or adjust the limit in plugin code.
AccessDenied / HTTP 403 Credentials do not have permission to list or read objects. Grant permissions for ListBucket and GetObject.
Connection refused / Host unreachable Endpoint URL or network configuration is incorrect. Verify endpoint, port, DNS, proxy and firewall settings.
Workspace is empty in pipeline stages Only the internal @script workspace was populated. For Pipeline script from SCM, add explicit checkout scm or checkout([$class: 'EndpointS3SCM', ...]) inside a stage to populate the main workspace.
